## 复现

```powershell
node node_modules/typescript/bin/tsc --noEmit -p src/Frontend/tsconfig.json
node scripts/build.mjs
dotnet build AxisLab.slnx -c Release -m:1 -nr:false
dotnet tests/CoreChecks/bin/Release/net10.0/AxisLab.CoreChecks.dll
dotnet tests/CommunicationChecks/bin/Release/net10.0/AxisLab.CommunicationChecks.dll
node scripts/program-checks.mjs
node scripts/modbus-checks.mjs
node scripts/desktop-checks.mjs
```

既有 ui/camera/motion-checks 使用独立数据目录与测试 Host，按项目 README 指定 AXISLAB_TEST_URL。程序和桌面脚本自行启动隔离实例，不修改用户工程。

## 限制

一个工程一个主程序，无并行流程或子程序。暂停在当前块结束后生效；最后一个块单步结束后可再继续确认完成。工作区最多 500 块/256 KiB，最大嵌套 24 层，运行最多 10000 个指令步骤和 600 秒活动时间。运动碰撞模型、图像缓存和渲染界面要求沿用前阶段。

新 C# 示例按 HTTP 程序控制；程序由核心持有，客户端退出不自动取消，需主动 stop。原 Modbus 直接动作保持控制权/心跳规则。
