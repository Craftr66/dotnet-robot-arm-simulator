# AxisLab 0.6.0 积木编程

本版本完成阶段 6 的编辑、执行和调试基础。积木使用本地 Blockly 13.4.0，程序由 C# 核心解释执行。三维场景、机器人运动、相机成像和外部 Modbus 功能继续复用。

## 第一次运行

1. 保存并关闭旧版，运行完整 `AxisLab-0.6.0` 文件夹中的 AxisLab.exe。
2. 导入 `Samples/block-programming.scene.json`，点击底部“积木编程”。
3. 点击“校验”，再点击“运行”。示例会把机器人移动到关节零位，拍照并判断成功，重复三次，在右侧显示“成功次数”和最近图像。
4. 点击“保存程序”会把当前积木同步至核心并保存整个工程。也可使用顶部“保存工程”。
5. 点击“导出程序”可单独保存程序 JSON；它保留设备和点位 UUID，在其他工程导入时需重新选择对应设备。

自己搭建时，从设备库添加机器人和相机，进入积木面板，点击工具箱分类，将“开始程序”拖入工作区，再将指令接到“执行”槽。所有启用指令须连到唯一的开始块；未连接的积木会阻止运行。也可点击“载入示例”生成基于当前设备的草稿。

示例不改变用户标定数据，不自动添加设备。若已有机器人示教点，模板优先使用第一台机器人的点；否则使用关节零位。运行前按自己的场景检查目标，限位、失效点或碰撞会阻止相应运动。

## 积木功能

| 分组 | 功能 |
| --- | --- |
| 流程与调试 | 开始、等待、重复次数、当条件为真循环、如果/否则、断点、日志 |
| 机械臂 | 关节 MoveJ、位姿 MoveJ/MoveL、移动到示教点 |
| 相机 | 拍照并等待完成、最近一次拍照是否成功 |
| 变量与数值 | 设置/增加数值变量、读取变量、数值常量、加减乘除 |
| 条件判断 | 真/假、数值比较、且/或/非 |

关节角使用 deg，位置使用 mm。三轴机器人只使用 J1—J3，J4—J6 必须为零；位姿块对三轴自动仅约束位置。运动块可选择机器人、速度及等待超时；位姿块支持 base/world/work 坐标。示教点按稳定 UUID 引用，失效点须先在“运动与示教”重新校验。

变量为数值，首次读取默认 0。名称以汉字、字母或下划线开头，最长 40 字，最多 64 个；数值范围限制为 ±1e12，除零会报告错误。日志中可写 `{变量名}` 显示当前值。布尔条件用于比较、逻辑和拍照结果，不与数值隐式混用。

拍照块是一个完整指令：触发后等待对应 CaptureId 完成，成功记录 FrameId 和图像地址。“失败继续”开启时，渲染未就绪、相机忙或超时会将结果设为假，流程可通过条件块处理；关闭时立即终止程序。不会把上一张成功图片当作本次成功。

## 运行和调试

| 操作 | 行为 |
| --- | --- |
| 校验 | 检查结构、表达式类型、设备/点位引用和点位失效；不运动 |
| 运行 | 先校验并应用草稿，再启动；运动路径到达该块时重新预检 |
| 单步 | 未运行时以单步启动；暂停时执行下一条完整指令，结束后暂停 |
| 暂停 | 完成当前运动、拍照或等待块后，在指令边界暂停；期间显示“当前块完成后暂停” |
| 断点块 | 执行到此处暂停，保留变量和程序位置 |
| 继续 | 从当前指令边界继续执行 |
| 停止 | 取消当前动作/捕获/等待和后续流程，保留实际仿真关节位置 |

循环和条件判断也计入指令步骤，开始图形和表达式不单独计步。最后一个块单步完成后可再按单步/继续，让执行器确认流程结束。再次“运行”会从程序开头执行并重新初始化变量，从机器人当前实际姿态规划，不自动恢复中断前的目标。

运行中高亮当前块，右侧显示状态、变量、错误、最近帧和最近 100 条日志，可导出日志。数值求解、限位和碰撞失败会停止程序，显示当前块与原因。校验错误可点击右侧提示定位对应块。

运行和断点暂停期间，场景、点位、程序编辑及保存锁定；单个工程只执行一个程序。外部 Modbus 不能抢占机器人，返回错误40 ProgramActive。界面停止、任意机器人停止以及退出桌面窗口都会取消当前程序。已有相机仍遵守每相机单次捕获的忙检查。

## 保存与引用

- 工程格式升级为 v5，保存积木工作区、设备/点位 UUID 和程序版本。可读取 v1—v4；旧软件不能读取 v5，请保留需要继续用旧版打开的副本。
- 草稿可以保存，即使尚未连完整；执行前必须校验通过。保存工程不自动恢复正在运行的命令。
- 设备改名会更新积木标签，UUID 保持；删除设备/点位后保留缺失引用并明确报错，不自动绑定新添加的对象。
- 程序单独导入/载入模板前如有草稿，会询问是否放弃。可先导出草稿备份。
- 其他客户端更新程序时，本地草稿保留并显示冲突；先导出需要保留的内容，再“重新载入”，避免静默覆盖。

## 当前限制

每个工程一个主程序，工作区最多 500 个积木（含表达式/影子块），程序 JSON 最大 256 KiB，流程/表达式嵌套最多 24 层。重复次数为 0—10000 整数，等待为 0—300 秒。每次运行最多 10000 个指令步骤、600 秒活动时间；断点暂停不消耗活动时间。

本阶段没有子程序、并行分支、跨设备同步运动、任意脚本执行、视觉坐标求解块或 IO/传送带块。已有运动学、碰撞、成像及图像缓存限制继续适用。视觉识别与标定训练是阶段 7 的工作。

## 外部 C# 运行程序

新示例在 `Samples/ProgramClient`，编译需要 .NET 10 SDK，无第三方 NuGet 包。先在界面保存程序，再使用软件“外部连接”显示的实际 HTTP 地址：

```powershell
$axisUrl = 'http://127.0.0.1:本次实际端口'
dotnet run --project .\Samples\ProgramClient -- $axisUrl validate
dotnet run --project .\Samples\ProgramClient -- $axisUrl run
dotnet run --project .\Samples\ProgramClient -- $axisUrl status
dotnet run --project .\Samples\ProgramClient -- $axisUrl step
dotnet run --project .\Samples\ProgramClient -- $axisUrl continue
dotnet run --project .\Samples\ProgramClient -- $axisUrl stop
```

`run/continue/step` 默认等待同一 RunId 完成或暂停；末尾加 `nowait` 仅提交。退出码 0=完成或操作已接受，2=校验未通过或等待到断点暂停，1=失败/取消/通信错误。暂停后可继续或停止。界面须保持打开以提供相机渲染。

程序由核心持有，HTTP 客户端退出后可继续运行；需要结束时主动 stop。原 `Samples/ModbusClient` 直接运动的控制权与 5 秒心跳规则保持不变。接口定义见《积木程序接口.md》。

技术参考：[Blockly JSON 工作区保存与加载](https://docs.blockly.com/guides/configure/serialization/)。本软件执行自有类型化指令树，未使用 JavaScript 代码生成器执行用户程序。
