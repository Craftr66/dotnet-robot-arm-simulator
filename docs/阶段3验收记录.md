# 阶段 3：虚拟相机拍照与传图、机械臂尺寸编辑 v0.3.0

日期：2026-10-20。完成“添加相机 → 拍照 → 预览/保存 → 独立 C# 收图”闭环，并加入本次提出的关节/连杆尺寸修改。阶段 4 的 Modbus 尚未实现。

## 实现

- 机器人属性提供 7 段长度、6 个关节直径与默认值恢复。几何写入工程，长度同步用于 FK、法兰/TCP 和末端挂载，直径更新三维外观。
- 工程格式 v3，兼容读取 v1/v2 并补齐默认几何，保留设备 ID、设备号、安装关系和已有角度。运动中结构编辑仍锁定。
- 单次针孔成像：每台相机自己的内参和世界矩阵驱动独立离屏渲染，包含真实场景设备，排除编辑辅助元素；不使用编辑器截图。
- 触发时在核心锁内冻结相机、场景和全体机器人状态。渲染消费冻结快照，PNG 与曝光 PoseId/关节/法兰/TCP 绑定；运动可以继续。
- CaptureId、FrameId、会话、配置版本和 SHA-256 贯穿队列、缓存、预览、导出与 HTTP 下载。失败不返回旧帧冒充新照片。
- 独占渲染租约、心跳、每相机忙状态、串行队列、超时、PNG 内容与尺寸检查、有界缓存和明确 410/404。
- 桌面 PNG/JSON 原生保存对话框，复制 HTTP 地址菜单；附 .NET 10 控制台示例，在动态端口触发并下载实际图像，校验摘要。
- 新增 `samples/camera-capture.scene.json`，提供可调六轴、固定全景相机、法兰工件观察相机、工作台和工件。

相机集成输出：`artifacts/camera-checks/results.json`、`top-camera.png`、`second-camera.png`、`sample-fixed.png`、`sample-hand.png`、`sample-ui.png` 及 C# PNG/帧 JSON。原有 UI 回归输出：`artifacts/ui-checks.json`。CoreChecks 日志中输出独立测试目录。

独立投影基准：相机 `(0,0,1000)`、`Rx=180°`，640×480，`fx=500, fy=450, cx=270, cy=190`；长方体中心 `(100,150,100)`、尺寸 `(80,60,60)`。八顶点解析投影范围 `(302.258,96.897)—(350.460,131.935)`；实际与空场景像素差分边界 `(302,97)—(350,131)`，四边差均小于 1 px。证明 CV 坐标方向、主点偏移及上下翻转与设定一致。验收阈值为 3 px，以容纳边缘抗锯齿。

几何基准：默认零位 TCP `(565,0,545)`；上臂由 300 改 420 后为 `(565,0,665)`；前臂由 280 改 380 后为 `(665,0,545)`。只改直径保持 TCP 不变。保存/重开和末端相机配对也有核心检查。

缓存与故障使用可控单调时钟及小容量测试配置验证，无需真实等待 12 s。真实窗口关闭后等待租约过期，HTTP 触发返回 503；不以伪造图片代替集成抓图。软件渲染 Edge/WebView2 用于稳定验收，结果不作为实际 GPU 性能承诺。

## 实现边界

无畸变、无噪声的单帧针孔相机；无视频流、视觉检测或标定求解。必须保持渲染窗口打开，无独立后台渲染。当前像素/缓存/裁剪/队列限制和错误码详见[使用说明](相机与尺寸使用说明.md)与[HTTP 接口](相机HTTP接口.md)。

运动继续使用简化关节插补；未增加 IK、MoveL、碰撞或动力学。关节直径用于外观，7 段长度影响运动学，不是任意 DH 表或品牌模型导入。尺寸变更后已有标定与点位在后续模块中需失效/复核。

已有图像帧是本次曝光的历史记录，之后修改配置不会改变其内容；活动捕获遇到配置变化则失败。图像和任务历史为内存缓存，退出不保留，需主动保存 PNG 和帧 JSON。持久化工程仅保存配置与当前关节位置。

## 依赖与下一步

继续使用 Three.js 0.180.0，无新增图像解码原生依赖。渲染实现依据官方 [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[WebGLRenderTarget](https://threejs.org/docs/pages/WebGLRenderTarget.html) 和 [Matrix4](https://threejs.org/docs/pages/Matrix4.html) 接口，并用上述像素基准实测验证。

下一阶段为通用 Modbus 与外部控制：冻结设备窗口、浮点字序、命令序号、控制权/心跳、停止与去重；C# 经 Modbus 读状态、受限关节动作和指定相机触发，再由帧令牌取得对应 HTTP 图像。不会在 Modbus 中传输 PNG 二进制。
