# 阶段 7B：标定对象与九点采样

日期：2026-10-21。版本：AxisLab 0.7.0 / AxisLab.WpfDemo 1.2.0。

## 实现范围

- 可添加、编辑、挂载和保存的九点标定板与单圆 TCP 靶标，真实相机渲染中可见。
- 标定板为局部 XY 平面 3×3 黑圆阵列；中心间距为板宽/高的三分之一。单圆靶标的特征中心为对象原点。
- 六轴＋固定相机的九点向导：读取中心 TCP、生成九个标定点与三个独立平移验证点、预检 MoveJ、停稳采集、按曝光实际 TCP 配对。
- PNG、去除相机真值的 observation.json、计划与 CSV 导出。像素坐标支持手动录入，重复/共线、缺失、非有限值及设备配置变化会被拒绝。
- VM 验证结果按帧和方案身份记录，独立平面误差报告含 RMS、最大误差及用户门限判定。
- 中文 VM 标定、字段配置、WPF 接入教程，示例场景与 GitHub 构建工作流。

## 边界

本轮完成采样底座，不宣称用户 .sol 已完成标定、识别或机器人视觉引导验收。三个额外点是独立平移验证点，不是旋转标定点。圆点不提供方向测量；Rz 为已知固定姿态时才可固定输入。报告范围为 XY 平面坐标转换，不代表完整三维手眼、旋转精度或抓放精度。

首版采样向导支持六轴、固定相机、TCP 零偏移圆点；生成新计划保留旧目录，重开窗口不自动恢复旧计划。继续使用原 schema v5 字段，新增设备类型要求新版软件读取。外部新增 Modbus 类型码 21（标定板）、22（圆点），仅有配置能力。

## 复现

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm run build
dotnet build AxisLab.slnx -c Release
dotnet build src/WpfDemo/AxisLab.WpfDemo.csproj -c Release
dotnet run --project tests/CoreChecks/AxisLab.CoreChecks.csproj -c Release
dotnet run --project tests/CommunicationChecks/AxisLab.CommunicationChecks.csproj -c Release
dotnet run --project tests/CalibrationChecks/AxisLab.CalibrationChecks.csproj -c Release
node scripts/calibration-checks.mjs
```

真实 SDK 回归还需本机厂商 SDK 与授权：`node scripts/wpf-framework-checks.mjs`。发布 WPF 目录后，设置 `AXISLAB_WPF_EXE` 再运行标定联调可检查自包含发布包。
