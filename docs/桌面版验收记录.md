# Windows 桌面交付验收：AxisLab 0.6.0

日期：2026-10-21。当前发布目标为 dist/AxisLab-0.6.0/AxisLab.exe 与完整 win-x64 ZIP，保留旧版目录。

本版增加离线 Blockly 工作区、程序保存、运动/拍照/条件循环、单步断点、高亮与日志，以及 C# ProgramClient。已有三轴/六轴运动、相机、Modbus 与原生文件操作继续可用。

- 独立 Windows 窗口、单实例激活、WebView 三维场景及原生保存/关闭对话框。
- 工程保存、未应用属性提醒、取消退出；机械臂尺寸改变真实 TCP。
- 三轴/六轴运动、位置 IK、示教点持久记录与 C# Modbus 示教动作。
- 相机实际 PNG、原生文件导出、固定帧 JSON、C# HTTP 校验及 Modbus 触发取图。
- 本地 Blockly 工作区、运动/拍照/判断循环完成，独立 C# 启动已保存程序并匹配完成结果。
- 无机器人运动的等待程序在窗口关闭确认前取消；取消退出后不恢复旧程序。
- 干净退出正常结束，HTTP 与 Modbus 监听均关闭，日志记录 DesktopStopped。

结果为 results.json；截图包括 desktop-blockly-ui.png、desktop-teaching-ui.png、desktop-camera-ui.png 和 desktop-webview.png。

## 运行及限制

保留完整发布目录，双击 AxisLab.exe；使用完整 ZIP 分享。程序本体无需 .NET SDK 或 Node.js，需 Microsoft Edge WebView2 Runtime；编译 C# 示例需要 .NET 10 SDK。检查不修改用户工程。

当前为自包含便携目录，尚无安装向导/签名，本机隔离运行时路径的检查未代替纯净 Windows 机器完整安装验证。运行能力和限制见阶段6验收记录；视觉识别与标定求解尚待阶段7。
