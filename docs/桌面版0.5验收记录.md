日期：2026-10-21。发布目录 `dist/AxisLab-0.5.0`，可执行文件 AxisLab.exe；分享时使用完整 win-x64 ZIP。旧版本目录及用户工程保留。

## 最终 EXE 验收

直接启动自包含发布 EXE，使用隔离数据与工作目录，DOTNET_ROOT 指向不存在路径，避免依赖开发电脑已有运行时。30 项全部通过，结果目录为 `artifacts/desktop-checks/1792551104157`。

- 独立 Windows 窗口、WebView 三维场景、动态 HTTP、内置 Modbus、自包含运行时。
- 单实例激活、工程本地保存、未应用属性的关闭提醒与取消。
- 修改机械臂尺寸影响真实 TCP，三轴严格三个关节。
- 相机实际渲染 PNG，HTTP 固定帧与原生文件对话框导出的图像一致，帧 JSON 身份一致。
- 外部 C# 读取图像并校验 SHA-256；Modbus 三轴动作、拍照、HTTP 下载。
- 新运动面板对三轴目标进行 IK 预检；示教点持久记录，C# 通过 Modbus 操作码9执行。
- 窗口关闭前停止关节；取消退出后机器人保持停止。干净退出正常结束，HTTP 与 Modbus 端口关闭，日志记录 DesktopStopped。

截图：desktop-teaching-ui.png、desktop-camera-ui.png、desktop-webview.png；结果：results.json，含发布 EXE 路径和逐项断言。

## 运行及限制

保存并关闭旧版后，双击新版 AxisLab.exe。保留完整发布文件夹，包含 wwwroot、运行时、WebView2Loader、Samples 和文档。无需 .NET SDK、Node.js 或浏览器启动步骤；需 Microsoft Edge WebView2 Runtime。C# 示例源码编译仍需 .NET 10 SDK。

当前为自包含便携目录，尚无安装向导或签名；在开发电脑隔离运行时路径的检查不代替纯净 Windows 机器完整安装测试。运动、碰撞、标定和积木的能力边界见《运动与示教使用说明》与阶段5验收记录。
