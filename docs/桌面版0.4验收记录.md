## 发行与边界

使用 scripts/publish-desktop.ps1 可复现发布。自包含 .NET / Windows Desktop / ASP.NET Core 10.0.12，WebView2 SDK 1.0.4258.31。运行 AxisLab 不需 SDK/Node.js；编译外部示例需 .NET 10 SDK。需保留完整文件夹，并具备 WebView2 Runtime。

默认 Modbus 仅监听 127.0.0.1:1502，HTTP 使用动态回环端口；界面可查看并复制连接信息，协议文件说明局域网启用方式。端口冲突有明确状态，软件不修改防火墙。外部连接已在本机独立进程验证，未在第二台实体电脑做路由/防火墙验收。

仍为便携目录版，无安装向导或签名；未在另一台纯净电脑验收。图像为内存缓存，退出清空，需保存 PNG 与帧 JSON。去重作用域为 TCP 连接，断线不自动续跑。现阶段无 IK、MoveL、碰撞、示教点、积木或视觉标定。

工程目录继续为 %LOCALAPPDATA%\AxisLab\Projects；新旧版本不共享未保存内存。0.4.0 保持 v3 并新增三轴类型，0.3.0 不认识该类型。升级前保存并备份工程，再关闭旧版。
