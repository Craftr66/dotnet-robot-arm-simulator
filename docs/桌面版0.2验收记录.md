# Windows 桌面交付验收：AxisLab 0.2.0

日期：2026-10-20。最终产物为 `dist/AxisLab-0.2.0/AxisLab.exe` 和 `dist/AxisLab-0.2.0-win-x64.zip`。新版采用独立目录，旧版 0.1.1 和用户工程数据保留。

## 当前实现

WPF/WebView2 原生窗口承载三维场景，ASP.NET Core 服务同进程运行并使用动态本机端口。保留原生菜单、文件保存对话框、未保存关闭确认和单实例管理。

0.2.0 加入六轴关节运动、速度限幅、回零/停止、正运动学、法兰/TCP 相机随动和 v1 工程迁移。尝试关闭窗口先停止运动，再询问是否放弃未保存修改；取消退出后机器人不自动续跑。

普通启动同一用户仍为单实例。显式设置独立桌面数据目录的验收实例使用目录作用域的互斥量和窗口标题，避免干扰正在使用的旧版或主工作区。

## 最终发布包验收

直接运行发布的 EXE，当前目录和数据目录均指向独立 artifacts 子目录。测试通过 16 项检查：

1. 自行启动动态 loopback 服务，不占用开发版 5080。
2. 存在真实 Windows 窗口句柄。
3. 内部服务健康正常。
4. 随包包含三个运行时；DOTNET_ROOT 指向不存在目录时仍能启动。
5. WebView 内加载场景编辑器。
6. 重复启动激活已有窗口，不创建第二套同目录服务。
7. 工程写入桌面用户数据目录。
8. 核心已保存时仍能检测前端属性草稿。
9. 原生退出确认可取消。
10. 桌面关节面板能启动核心运动。
11. 尝试关闭窗口在确认前停止运动。
12. 取消退出后关节保持停止位置。
13. 内嵌 WebGL 有效。
14. 保存后关闭正常退出，退出码 0。
15. 应用退出后内部服务停止。
16. 日志记录 DesktopStopped。

结果和截图：`artifacts/desktop-checks/1792485412166/`。脚本：`scripts/desktop-checks.mjs`、`scripts/desktop-window.ps1`。自动化参考[微软 Playwright WebView2 文档](https://github.com/microsoft/playwright/blob/main/docs/src/webview2.md)。调试端口仅在显式测试参数下启用，普通启动不启用。

共用核心通过 60 项检查，浏览器/API 通过 32 项检查。TypeScript 严格检查及 C# 发布编译成功，无编译警告或错误。运动学基准详见[阶段 2 验收记录](阶段2验收记录.md)。
