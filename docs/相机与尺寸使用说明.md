# AxisLab 0.6.0：机械臂尺寸与相机拍照

日期：2026-10-20。新增机械臂尺寸编辑，完成阶段 3 的虚拟相机拍照与 HTTP 传图。

## 修改机械臂尺寸

添加或选择六轴机械臂，在右侧“机械臂尺寸”中设置参数，再点击“应用属性”。“恢复默认尺寸”先填写默认值，仍需应用才会生效。编辑时可向下滚动属性面板。

| 参数 | 默认 / mm | 作用 |
| --- | --- | --- |
| 基座高度 | 135 | 世界安装原点到 J1 的 Z 偏移 |
| 肩部高度 | 110 | J1 到 J2 的 Z 偏移 |
| 上臂 | 300 | J2 到 J3 的局部 Z 偏移 |
| 前臂 | 280 | J3 到 J4 的局部 X 偏移 |
| 腕段 J4→J5 | 80 | 局部 X 偏移 |
| 腕段 J5→J6 | 70 | 局部 X 偏移 |
| J6→法兰 | 55 | 局部 X 偏移，法兰另含固定 Ry=90° |
| J1/J2/J3 直径 | 各 110 | 外观尺寸 |
| J4/J5/J6 直径 | 各 74 | 外观尺寸 |

长度范围 5—3000 mm，基座高度至少 40 mm；直径范围 10—500 mm。长度同步影响 FK/IK、法兰、TCP 和末端相机；直径影响外观与基础碰撞代理。轴向、零位和角限位保持通用 6R 模型定义。运动中不能修改尺寸。当前包含基础碰撞检测，不含动力学，尺寸编辑不代表新增精确品牌机器人模型。

尺寸写入工程 v5，v1/v2/v3 导入时补齐默认值，ID、设备号和挂载引用保留。改尺寸后保存会写为 v5，建议保留旧工程副本。示教点会标为待校验，需按新几何重新校核；标定功能按后续阶段接入。

## 添加相机并拍照

1. 添加“针孔相机”，独立安装或选择机器人父对象及 base/flange/tool 挂载。
2. 配置位置、旋转、图像宽高与内参，点击“应用属性”。绿色视锥指向相机正前方。
3. 选择相机或点击下方“相机画面”，选择要使用的设备。
4. 等待“相机成像就绪”，点击“拍照”。“朝向机械臂”可辅助调整相机方向，随后仍可手动设置。
5. 预览成功后，“保存 PNG”保存原始分辨率图像；“导出帧信息”保存配对的 JSON。桌面使用原生 Windows 保存对话框。

可从 Samples 导入 `camera-capture.scene.json`。固定全景相机观察机械臂和工作台；法兰相机观察工件，可运动后重新拍照比较。

相机坐标使用 +X 向右、+Y 向下、+Z 向前。世界/机械臂为右手系、长度 mm、旋转 deg，姿态矩阵采用列主序，`p_world = T_world_camera × p_camera`，Euler 为 `Rz × Ry × Rx`。成像满足 `u=fx·X/Z+cx`、`v=fy·Y/Z+cy`，原点在图像左上。当前无畸变、噪声、曝光模糊或连续预览；每次触发生成一帧。

图像包含可见设备、灯光与平面地面，编辑网格、坐标轴、选择框和视锥不入照片。当前相机自身外壳从照片中排除；其他相机外壳可见。隐藏父对象同时隐藏其子对象。近裁剪 1 mm、远裁剪 30000 mm；地面为 6000×6000 mm。无阴影、物理纹理和视觉检测。

## C# 取图

保持 AxisLab 窗口打开，使用“工具 → 连接信息”查看本次地址，或“复制 HTTP 连接地址”。桌面端口每次启动自动分配，开发模式默认 `http://127.0.0.1:5080`。

在 `Samples/CSharpClient` 目录中用 .NET 10 SDK 执行，端口替换为实际值：

```powershell
dotnet run -- http://127.0.0.1:实际端口 first ./captures
```

示例会列出设备，可用相机 ID 替换 `first`，依次触发、等待、下载 PNG 和帧 JSON，并核对 SHA-256。AxisLab 本身使用无需 SDK；编译此示例需要 SDK。协议见《相机HTTP接口.md》。

## 帧配对和限制

触发时核心原子冻结场景、相机世界坐标及机器人姿态，记录曝光时刻；渲染端消费该快照。运动在后续继续时，图片仍对应曝光快照中的 PoseId、关节、法兰和 TCP。成功返回新的 CaptureId 与 FrameId；按固定 FrameId 下载，避免“最近一张图”造成串帧。

当前图像宽高各 64—4096 px，单帧总像素不超过 4194304，PNG 不超过 8 MiB。每相机最多一个活动捕获，所有相机共用串行渲染器，队列最多 8 个。捕获超时 12 s，渲染租约 4 s、心跳约 1 s。多窗口共用一个渲染器，其他窗口仍可触发和读取。

图像只保存在内存：每相机最近 20 帧且全局不超过 256 MiB，先达到的限制先淘汰。元数据记录有界保留最多 512 项；已淘汰帧或工程会话变化返回 410，更早记录清理后返回 404。捕获状态最多保留 256 项。退出软件丢失缓存，需主动保存图像和 JSON；工程文件不嵌入图像。

关闭渲染界面时触发返回 503；相机忙返回 409。拍照中更改场景/相机配置会使捕获失败，需重新触发；渲染中断、超时和无效 PNG 都有明确失败状态。当前未实现无界面成像；最小化或后台窗口的系统节流也可能导致超时。

Modbus、C# 外部动作、示教和积木编程已接入，见《外部连接快速开始.md》和《积木编程使用说明.md》。下一阶段开始视觉识别与标定训练。
