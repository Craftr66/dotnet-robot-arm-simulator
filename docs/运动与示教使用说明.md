# AxisLab 0.6.0 运动与示教

本阶段支持三轴 3R 和六轴 6R 的目标位姿运动、直线运动、工具与工件坐标设置，以及示教点保存和回放。积木拖拽编程已在阶段 6 接入，见《积木编程使用说明.md》；标定采样和求解向导在阶段 7 实施。

## 快速练习

1. 保存并退出旧版本，运行完整 `AxisLab-0.6.0` 文件夹中的 `AxisLab.exe`。
2. 导入 `Samples/five-point-teaching.scene.json`，选择六轴机械臂，点击底部“运动与示教”。
3. 选择 MoveJ、50% 速度，点击“顺序回放”。状态栏显示当前步骤和进度，五个点逐点停稳。
4. 选择其中一个点，点击“单步运行”。“停止”或顶部“停止运动”会立即终止后续插补，保持当前仿真关节位置；再次回放从实际位置重新规划。
5. 点击“读取当前 TCP”，改动少量 X/Y/Z，选择 MoveL，先“预检目标”，再“执行目标”。遇到不可达、限位、奇异分支或碰撞，会给出原因并阻止启动。

也可以新建空白工程，添加机械臂，再从“关节点动”设置较舒展的姿态，例如六轴 `15,-15,20,10,25,-5` deg。零姿态六轴腕部可能接近奇异，建议从舒展姿态开始练习完整位姿运动。

## 坐标与运动

| 选项 | 含义 |
| --- | --- |
| 机械臂基坐标 base | TCP 相对所选机器人基座；不包含基座安装位姿 |
| 世界坐标 world | TCP 相对场景原点；包含基座安装平移和旋转 |
| 工件坐标 work / W | TCP 相对该机器人设置的工件坐标；W 的位姿定义在机器人基坐标中 |
| 工具 TCP / T | 相对法兰 F 的工具原点和姿态，影响 FK、IK、直线插补和末端相机挂载 |
| MoveJ | 求目标 IK，再进行关节空间插补；中间 TCP 通常走曲线 |
| MoveL | TCP 沿空间直线，姿态按四元数最短旋转插补；逐段 IK 连续求解 |
| 只约束位置 | 仅保证 XYZ，姿态由求得的关节决定；三轴固定启用，六轴可选 |

单位为 mm 和 deg；姿态采用 `Rz · Ry · Rx`。矩阵为权威值，欧拉角在 ±90° 附近可能换一种等价显示。切换目标坐标系后，请重新“读取当前 TCP”或填写相应坐标系下的数值，界面保留数值不会自动替你解释旧输入。

右侧对象属性新增“工具 TCP · 相对法兰 F”和“工件坐标 W · 相对基坐标”。填写六个分量，点击“应用属性”。三维视图显示所选机器人的 W 坐标轴和近期 TCP 轨迹；轨迹仅用于观察，不写入相机照片和工程。当前工具、工件坐标由用户手动输入，自动标定尚未接入。

预检会返回关节解、估计时长和提示，实际关节保持不动。执行时再次按最新状态预检。数值 IK 从当前关节附近尝试有限数量的种子，可能有多解；失败表示当前算法未找到满足限位与误差条件的解，不代表数学上已证明全局无解。三轴无法同时独立指定完整六维姿态。

## 示教点

示教点记录实际关节位置、TCP 在所选坐标系下的位姿、稳定 ID/编号及几何依赖。

| 操作 | 行为 |
| --- | --- |
| 记录当前 | 用名称栏的新名称记录当前实际姿态；机器人须停止且无外部控制权 |
| 改名 | 仅修改选中点名称，保持编号、位置和依赖记录 |
| 覆盖当前 | 用机器人当前实际关节和 TCP 覆盖选中点，保留原名称和编号 |
| 重新校验 | 按保存的关节重新计算 TCP、检查该姿态碰撞并更新依赖；不会让机器人运动 |
| 删除 | 删除选中点；删除编号不再复用 |
| 单步运行 | 按所选 MoveJ/MoveL、速度执行选中点 |
| 顺序回放 | 按列表创建顺序执行该机器人全部点；启动前预检整组动作，任一点失败则整组不启动 |

MoveJ 使用保存的关节；MoveL 使用保存的 TCP 位姿和坐标系连续求解，最终关节可能为另一组等价解。点与点之间停稳，暂不做圆滑过渡。HTTP 可以显式给出点 ID 数组，自定义顺序或重复次数。

修改连杆/直径、TCP、工件坐标、基座安装或场景障碍物后，相关点会显示“待校验”，不能回放。改名称和正常关节运动不会使点过期。**重新校验会按原关节重新计算坐标，可能改变原有 TCP 位置**；若要保持原工件上的物理目标，应重新定位再“覆盖当前”。即使点未过期，每次运行仍会重新检查整条路径。

点击“保存工程”将点写入工程 JSON。导出/导入也保留点位。工程格式为 v5，可读取 v1/v2/v3/v4；旧软件不能读取 v5，升级前请备份需要继续在旧版使用的工程。删除机器人会删除其示教点，复制机器人仅复制设备及当前关节，不复制点位。每工程最多 256 个示教点。

## 速度、碰撞与限制

关节路径使用五次时间曲线，端点速度与加速度为零；按每轴最大速度和 `2 × 最大速度` 的加速度基准乘速度倍率计算时长。MoveL 另设 TCP 250 mm/s、旋转 45 deg/s 的基准上限。速度倍率 1—100%；接近奇异的笛卡尔规划限制至 10%。单段最长 120 s。

MoveL 通过位置线性插值、姿态 SLERP、连续 IK 和关节三次 Hermite 插值生成路径。规划中加密检查，目标位置误差 0.05 mm、姿态误差 0.05°；验收采样容差另留求解数值余量。当前每条 MoveL 最多 512 段，碰撞最多 8192 个采样区间；整组回放预检共享约 2.5 s 的计算预算；复杂路径或超时返回 PlanningLimit，可拆成几个动作或点位组。MoveJ 与 MoveL 都在启动前检查路径，执行时继续检查运动状态。

基础碰撞模型覆盖地面、机械臂非相邻连杆/关节、机器人基座、其他机器人及可见长方体。连杆使用胶囊、关节使用球体、工具用半径 8 mm 的线段代理，长方体使用带保守膨胀的有向包围盒。相邻连接部位、相机外壳及自身挂载物没有完整碰撞模型；隐藏长方体不作障碍物。极端尺寸、贴近接触或复杂挂载请保持间距。运动基座须独立固定，机器人间嵌套挂载不支持运动。

预检失败保持原姿态。执行期间若与另一台运动机器人发生干涉，会终止当前活动动作、保留上次通过检查的位置并撤销外部控制权。当前为教学运动仿真，无自动绕障、网格精确接触、动力学、真实制动过程或负载计算。

算法实现参考 [Modern Robotics 数值 IK](https://modernrobotics.northwestern.edu/nu-gm-book-resource/6-2-numerical-inverse-kinematics-part-1-of-2/)和[点到点时间参数化](https://modernrobotics.northwestern.edu/nu-gm-book-resource/9-1-and-9-2-point-to-point-trajectories-part-2-of-2/)，采用本项目运动学模型和有限计算预算。

## 外部 C# 操作

先从软件“外部连接”查看本次 HTTP 地址。源码项目根目录使用 `samples/ModbusClient`，发布目录使用 `Samples/ModbusClient`。

```powershell
$axisUrl = 'http://127.0.0.1:本次实际端口'
dotnet run --project .\Samples\ModbusClient -- $axisUrl list
dotnet run --project .\Samples\ModbusClient -- $axisUrl state 1

# 关节目标，机器人编号以设备列表为准
dotnet run --project .\Samples\ModbusClient -- $axisUrl move 1 15,-15,20,10,25,-5 50

# 位姿目标：X,Y,Z,Rx,Ry,Rz；数值必须按自己的工程填写
dotnet run --project .\Samples\ModbusClient -- $axisUrl movepose 1 420,130,410,168,60,-173 25 base
dotnet run --project .\Samples\ModbusClient -- $axisUrl movel 1 415,135,415,168,60,-173 25 base

# 六轴仅约束 XYZ：末尾 position；三轴自动按位置目标执行
dotnet run --project .\Samples\ModbusClient -- $axisUrl movepose 1 415,135,415,0,0,0 25 base position

# 运行点编号 1（机器人编号 1）；点必须存在且已校验
dotnet run --project .\Samples\ModbusClient -- $axisUrl teach 1 1 50
dotnet run --project .\Samples\ModbusClient -- $axisUrl stop 1
```

客户端自动申请控制权、更新心跳、等待完成并释放。Modbus 新增操作码 7/8/9，定义见《运动与示教接口.md》；原操作码 1—6 保留。图像仍经 Modbus 触发、HTTP 下载，具体见《外部连接快速开始.md》。
