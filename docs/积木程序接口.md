# AxisLab 0.6.0 积木程序 HTTP 接口

HTTP 前缀 `/api/v1`，JSON。程序运行接口作用于当前工程；设备控制继续使用既有 Modbus/HTTP。新程序接口没有新增 Modbus 操作码。

| 方法和路径 | 请求 / 结果 |
| --- | --- |
| GET /project | project.program 返回 ProgramDefinition，schemaVersion=5 |
| PUT /program | `{expectedRevision,program}`；应用源数据，返回 WorkspaceSnapshot；落盘仍需 POST /project/save |
| POST /program/validate | `{program}` 或 `{}` 校验当前保存的程序；返回 valid、diagnostics、blocks |
| POST /program/run | `{expectedRevision,singleStep:false}`；校验并启动，返回运行状态 |
| GET /program/status | 当前运行状态、RunId、当前块、变量、最近帧、最近 100 条日志 |
| POST /program/pause | 无业务字段；请求当前块结束后暂停 |
| POST /program/continue | 从 Paused 继续 |
| POST /program/step | 从 Paused 执行下一步；首次单步使用 run 的 singleStep=true |
| POST /program/stop | 停止当前程序；重复停止不重启程序 |

程序定义：

```json
{
  "version": 1,
  "name": "主程序",
  "workspace": {
    "blocks": {
      "languageVersion": 0,
      "blocks": [{
        "type": "ax_start", "id": "start-id",
        "inputs": { "BODY": { "block": {
          "type": "ax_log", "id": "log-id",
          "fields": { "TEXT": "程序开始" }
        } } }
      }]
    }
  }
}
```

workspace 为 Blockly JSON；允许的自定义块来自当前编辑器。程序保存时检查结构/版本/大小和块 ID，允许未完成的草稿；运行前编译器检查唯一开始块、连接关系、类型、引用和示教依赖。不会执行 JSON 中的任意脚本。

校验失败示例：`{valid:false,diagnostics:[{blockId:"...",code:"MissingDevice",message:"..."}],blocks:[...]}`。缺失/失效设备和点位要明确修复，不能用同名对象或列表索引代替。运动块的实际可达性与碰撞在执行该块前用当前状态检查。

## 状态与取消

运行状态包含 sessionId、runId、status、activeBlockId、activeOperation、executedBlocks、activeSeconds、errorCode、message、variables、lastCapture、logs、active。

| status | 含义 |
| --- | --- |
| Idle | 当前会话尚未运行程序 |
| Running | 正在执行 |
| Pausing | 请求已接受，等待当前块结束 |
| Paused | 断点、单步或边界暂停，仍持有工程运行权 |
| Completed | 全部执行完成 |
| Failed | 当前块或运行预算失败，已停止动作 |
| Cancelled | 被停止或控制权撤销 |

run 返回仅表示程序启动。轮询 status 时必须匹配 sessionId 和 runId，再判断终态；不能只检查 errorCode 是否为空。新建/导入/重开工程不恢复旧执行器。HTTP run 无跨重试去重，超时后应先查询 status，确认运行身份后再决定是否重试。

程序执行期间锁定场景、点位、工程保存和其他机器人控制；暂停仍保持锁定。stop、桌面关闭或本地机器人停止取消当前运动与本程序的捕获请求，并取消后续指令。程序是核心持有的本地任务，HTTP 客户端断开不自动停止；需要显式 stop。

暂停为指令边界语义；不会在机器人或相机执行一半时把其标为 Paused。单步包含完成一条运动/拍照/等待块，控制块也计步；开始图形及表达式不单独计步。

lastCapture 含 cameraId、captureId、success、frameId、imageUrl、errorCode 和 message。成功后 imageUrl 可下载相同 PNG；图像遵循既有缓存期限，不嵌入项目。拍照失败时 success=false 且没有成功 frameId。

## 常见错误

- ProgramInvalid：运行前校验失败；先调用 validate 取得逐块诊断。
- ProgramActive / ProgramBusy：运行或断点暂停期间冲突。
- ProgramNotPaused / ProgramNotRunning：状态不满足操作要求。
- MissingDevice / MissingTeachPoint / StaleTeachPoint：引用缺失或依赖失效。
- ExpressionType / MissingInput / InvalidVariable：表达式或参数无效。
- DivisionByZero / ExpressionRange / InvalidRepeat / InvalidWait：运行时数值错误。
- InstructionTimeout / ProgramTimeout / ProgramStepLimit：超时或指令预算超限。
- 运动和相机沿用 IkUnreachable、CollisionDetected、RendererUnavailable、CaptureTimeout 等错误。

Modbus 原地址与操作码 1—9 保留。寄存器2更新为软件标志6；程序持有机器人期间，寄存器14显示2（其他控制者），申请/运动冲突返回业务错误40 ProgramActive。完整映射以 `/communication/map` 或随包 Modbus-v1-map.json 为准。
