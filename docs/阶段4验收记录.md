# 阶段 4：Modbus 外部控制与三轴机械臂 v0.4.0

日期：2026-10-21。已实现稳定设备寻址、Modbus TCP、C# 关节控制/停止/相机触发与 HTTP 固定帧取图，新增用户确认的通用三轴 3R。

## 交付范围

- 三轴/六轴统一模型分派，按实际轴数执行限位、关节插补、点动/回零、FK、法兰/TCP、几何编辑与末端挂载；混合场景添加时机器人错开放置。
- 三轴 J1=Z、J2/J3=Y，沿用肩/上臂/前臂，去掉腕段；工程 v3 保持设备 UUID、编号和几何。旧六轴工程兼容。
- 独立 Modbus TCP 监听，默认 127.0.0.1:1502、Unit ID=1，FC03/06/16，真实 MBAP 拆包/粘包、数量/字节数/地址检查、标准异常和事务号回传。
- 每 TCP 连接独立选择、暂存和结果；以工程会话、UUID 和配置版本校验设备，避免编号复用或工程切换后的旧命令误执行。
- 按机器人分配外部控制权，变化的心跳续期，5 秒超时或 TCP 断线停止；本地停止可撤销外部控制。
- 原子提交非零递增序号，同序号同参数返回原命令；冲突或已清理的旧序号拒绝，连接内历史有界保留。
- Modbus 操作码 5 触发指定相机，结果 sessionToken/frameToken 解析为既有固定 FrameMetadata，再下载 PNG；支持取消本连接捕获。
- 顶部外部连接、原生连接信息/复制、寄存器 JSON 导出；独立 C# 客户端与完整中文连接/操作协议。
- 新场景 `samples/external-control.scene.json` 包含三轴、六轴、两相机、工作台与工件。

## 边界与下一步

本次外部控制实测为本机独立进程与隔离 TCP 连接；局域网监听已提供配置，但未使用第二台实体电脑完成防火墙/路由端到端验收。默认仅回环监听，软件不改防火墙。无登录/TLS，协议用于可信仿真实验网。

去重按 TCP 连接，重连必须重新核对设备与会话；当前不自动续跑断线动作。单连接一次选择一个设备，最多 16 活动连接、64 连接历史，每连接 128 命令历史、512 帧映射。图像缓存遵循阶段 3 的限制。协议版本 1 暂无 IO、传送带、视觉识别、示教点或程序积木操作码。

当前仍是关节插补，无 IK、MoveL、加减速和碰撞检测。下一阶段为完整运动与示教，再进入拖拽编程和视觉/手眼标定。
