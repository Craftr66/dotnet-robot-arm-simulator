# C# 相机取图示例

需 .NET 10 SDK。先运行 AxisLab 0.3.0，在场景里添加相机并等待“相机成像就绪”，保持软件窗口打开。通过桌面原生菜单“工具 → 连接信息”获取本次启动的地址；开发模式默认 `http://127.0.0.1:5080`。

在此目录执行（端口替换为界面给出的实际端口）：

```powershell
dotnet run -- http://127.0.0.1:实际端口 first ./captures
# 指定相机：将 first 改为软件属性面板或 GET /api/v1/devices 返回的完整稳定 ID。
```

程序列出相机，触发指定相机，轮询捕获状态，按固定 FrameId 下载 PNG 与帧信息，核对 SHA-256 并保存。帧信息包含内参、曝光时相机世界矩阵、机械臂 PoseId/关节/法兰/TCP，后续可用于标定。图像缓存最多每相机 20 帧、总计 256 MiB；淘汰或工程切换后 HTTP 410，需重新触发。

无渲染窗口时返回 503；相机忙返回 409；超时和渲染失败在捕获状态中返回。此例使用 HTTP 二进制传图，Modbus 在下一阶段接入。
