# AxisLab Windows 桌面版 0.6.0

桌面版已完成阶段 6，提供离线积木编程、运动与拍照流程、变量与条件循环、单步/断点/停止、日志及 C# 程序控制。视觉识别与标定算法将在阶段 7 接入。

## 直接运行

1. 先保存并退出旧版 AxisLab。
2. 将 `AxisLab-0.6.0-win-x64.zip` 解压到一个普通文件夹。
3. 双击解压后的 `AxisLab-0.6.0/AxisLab.exe`。
4. 等待场景界面加载，即可添加三轴/六轴机械臂、相机和几何体。

必须保留完整文件夹，包括 `wwwroot`、运行时 DLL、WebView2Loader 和 Samples，不能只复制 EXE。该包为 Windows x64 自包含目录发行版，无需安装 .NET SDK、Node.js 或前端构建工具，也无需手动启动服务或浏览器。

电脑需有 Microsoft Edge WebView2 Evergreen Runtime。当前开发电脑已安装；其他电脑缺少时应用会显示安装提示，可从[微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/)安装。此包未包含 WebView2 离线运行时。版本尚未做代码签名，也不是安装向导包。

## 工程与退出

- 添加/编辑对象后，先“应用属性”，再“保存工程”。
- 选择机械臂，在下方“关节点动”设置目标角、点击增减点动、回零或停止；速度倍率与步长可选。
- 右侧“机械臂尺寸”支持 7 段长度与 6 个关节直径。长度影响 FK/IK，直径影响外观和基础碰撞，编辑后应用并保存。
- 选择相机后，在下方“相机画面”拍照、预览、保存 PNG 和导出帧信息；图片不嵌入工程。
- “工具 → 复制 HTTP 连接地址”可复制本次服务地址，`Samples/CSharpClient` 提供 C# 触发取图示例；取图时保持软件窗口打开。
- 图像最多每相机 20 帧、全局 256 MiB，退出后缓存清空。详细参数、坐标、错误与限制见随包的《相机与尺寸使用说明.md》和《相机HTTP接口.md》。
- 相机选择机器人为父对象后，可选择“机器人法兰 F”或“TCP / 工具 T”随动。挂载前后保留局部位姿，世界位置可能变化。
- 运动中不能编辑或保存场景；先停止或等待完成。当前采用五次时间插补和基础碰撞预检；“运动与示教”支持目标位姿、直线运动和示教点回放，详见随包《运动与示教使用说明.md》。
- 关闭窗口会先停止机械臂，再检查未保存修改；选择返回后保持停止状态。
- v1/v2/v3/v4 工程可以打开并自动补齐参数，保存时写入 v5。旧版本不支持 v5，原始工程可先用文件副本保留。
- 工程文件保存在 `%LOCALAPPDATA%\AxisLab\Projects`；菜单“工具 → 打开工程文件夹”可以直接访问。
- 浏览器数据位于 `%LOCALAPPDATA%\AxisLab\WebView2`，启动日志位于 `%LOCALAPPDATA%\AxisLab\desktop.log`。
- 可使用菜单“文件 → 导入 JSON 工程”打开旧网页版本导出的文件，或原项目 `data/projects` 目录中的 `.scene.json`，再保存到桌面数据目录。旧数据不会自动迁移或删除。
- 示例放在程序旁的 `Samples` 目录，可通过“工具 → 打开示例文件夹”访问。
- 导出会弹出原生 Windows 保存对话框；文件选择也使用系统对话框。
- 关闭窗口会检查未保存的工程、工程名称和属性修改；选择“否”可返回继续保存，选择“是”才放弃退出。
- 内部服务在同一进程启动，使用自动分配的本机端口；窗口关闭后服务停止。不会占用网页开发版的固定 5080 端口。
- 重复双击会激活已有桌面窗口。同一 Windows 用户默认只运行一个桌面实例。

更新时关闭应用，替换程序目录，用户数据目录保持不变。备份工程可复制 Projects 目录或在软件内导出 JSON。

## 从源代码构建

开发需要 .NET 10 SDK、Node.js 和已安装的前端依赖。先构建本地前端，再发布桌面应用：

```powershell
.\scripts\publish-desktop.ps1
```

输出 `dist/AxisLab-0.6.0/AxisLab.exe` 和 `dist/AxisLab-0.6.0-win-x64.zip`。首次发布需从 NuGet 下载 WebView2 组件和 .NET 自包含运行时。已有前端构建可用 `-SkipFrontend`。

开发调试可先执行 `node scripts/build.mjs`，再运行 `dotnet run --project src/Desktop/AxisLab.Desktop.csproj -c Release`。服务启动与资源查找不依赖终端当前目录。

本机有 .NET 运行时并不等于验证了在纯净机器上的安装；当前验收范围、桌面检查结果与限制见项目内桌面版验收记录。


## 外部连接

点击顶部“外部连接”查看实际 HTTP 与 Modbus 端口并导出寄存器映射。默认 Modbus 127.0.0.1:1502、Unit ID=1。C# 外部动作与拍照示例位于 Samples/ModbusClient；导入 Samples/external-control.scene.json 可按固定示例编号练习。完整步骤见随包《外部连接快速开始.md》，协议见《ModbusTCP操作协议v1.md》。

外部机器人控制需要先申请控制权，1 秒更新一次变化的心跳计数；5 秒未更新或 TCP 断线即停止。运动或外部持权期间场景编辑锁定，本地停止可撤销外部控制。默认仅本机监听，局域网启用方式、端口冲突处理和图像下载方法均见快速开始。


## 积木程序

导入 Samples/block-programming.scene.json，点击底部“积木编程”，校验后运行。保存程序会同时保存工程（v5），可读取 v1—v4。详细操作见《积木编程使用说明.md》，外部 C# 程序控制见 Samples/ProgramClient 和《积木程序接口.md》。运行和断点暂停期间锁定场景，停止或退出会取消当前动作、拍照及等待。
