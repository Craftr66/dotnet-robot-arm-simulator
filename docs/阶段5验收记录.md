## 限制与后续

碰撞采用保守几何代理，未覆盖相邻连接部位、相机外壳和自身挂载物的完整网格；不具备自动绕障、动力学和真实制动模拟。数值 IK、直线路径与预检有采样/时间预算，极端参数可返回不可达或 PlanningLimit。示教回放逐点停稳，无路径融合，列表按创建顺序；自定义顺序可通过 HTTP 点 ID 数组传入。

当前发布为 Windows x64 自包含便携目录，需 WebView2 Runtime；无安装向导/签名，未代替纯净机器完整安装验收。v4 工程可由本版本读取，旧软件不能读取 v4，升级前保留所需副本。
